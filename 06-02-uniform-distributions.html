    MATH 11

    Continuous Uniform Density Function

    Definition 6.2.1

    A continuous uniform density function is a probability density function whose output value remains the same for all values of the random variable. So f(x)=h for some constant value h.

    The total area must equal 1. If the interval has length w, what is h?

    §6.2 A Continuous Uniform Density Function

    MATH 11

    The Height of the Density

    The interval on which f is defined must have a finite length. If that interval has length w, then h=1w is the height of the density that makes the total area equal to 1.

    §6.2 A Continuous Uniform Density Function

    MATH 11

    Uniform Distribution

    Definition 6.2.3

    A (continuous) uniform probability distribution function (uniform PDF) or “uniform distribution” for short, is a continuous probability distribution in which the probability density function is a uniform probability density function.

    The notation X∼U(a,b) means that X is a random variable for a (continuous) uniform distribution where a is the lowest value of x and b is the highest value of x.

    In Example 1, X∼U(20,45).

    §6.2 Determining Uniform Probabilities

    MATH 11

    Determining Uniform Probabilities

    For a uniform distribution X∼U(a,b), the probability that X falls in an interval is the length of that interval divided by the total length b−a.

    Theorem 6.2.4 Uniform Distribution Probability Formula

    For a uniform distribution X∼U(a,b), the probability that X is between two values c and d (where a≤c<d≤b) is P(c≤X≤d)=d−cb−a.

    §6.2 Example 2

    MATH 11

    An Order Within 30 Minutes

    For Example 1, what is the probability that the order will arrive within the next 30 minutes?

    We found the density f(x)=125 for 20≤x≤45.

    We need P(20≤X≤30), which is the area of the rectangle from x=20 to x=30:

    P(20≤X≤30)=10⋅125=25.

    A bakery’s ovens turn out sourdough loaves. Let X be the weight of a randomly chosen loaf, in grams. Assume that X∼U(450,470).

    Find the probability that the weight of a randomly chosen loaf is at least 462 grams. Round your answer to four decimal places.

    §6.2 Practice

    MATH 11

    You Try 6.2.1: Checking Your Answer

    We have X∼U(450,470), so the density is f(x)=120 for 450≤x≤470.

    We want P(X≥462). Since X only takes values up to 470, this is the same as P(462≤X≤470).

    P(462≤X≤470)=8⋅120=820=0.4000

    §6.2 Example 3

    MATH 11

    Mean and Standard Deviation

    For the food delivery scenario in Example 1, find the mean and standard deviation of the waiting time. Round to two decimal places if necessary.

    We have X∼U(20,45), so a=20 and b=45.

    μ=20+452=32.5 minutes
    σ=45−2012=2512≈7.22 minutes.

    On average, a customer waiting for an order will wait 32.5 minutes for the order to arrive.
