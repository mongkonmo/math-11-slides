    §9.3 General Procedure

    MATH 11

    General Procedure

    Procedure 9.3.1 General Procedure for Hypothesis Testing
    1. Verify that the requirements for the test are satisfied.
    2. Identify the null and alternative hypotheses (H0 and H1).
    3. Determine the type of test (left-tailed, right-tailed, or two-tailed).
    4. Collect data from a sample and calculate the sample statistic.

    §9.3 General Procedure

    MATH 11

    General Procedure

    Procedure 9.3.1 General Procedure for Hypothesis Testing (continued)
    1. Calculate the test statistic using the appropriate formula.
    2. Use either the P-value method or the critical value method to make a decision.
    3. State the conclusion of the test in non-technical terms.

    §9.3 Test Statistics

    MATH 11

    Test Statistics

    Definition 9.3.2

    A test statistic is a value calculated from the sample data that is used to determine whether to reject the null hypothesis. The test statistic measures how far the sample result is from what we would expect if the null hypothesis were true.

    §9.3 Test Statistics

    MATH 11

    Test Statistics

    The formula for the test statistic depends on the parameter being tested:

    • For population proportions: we use a z-score.
    • For population means with known σ: we use a z-score.
    • For population means with unknown σ: we use a t-score.
    • For population variances: we use a χ2-score.

    The specific formulas will be covered in the next chapter.

    §9.3 The P-Value Method

    MATH 11

    The P-Value

    Definition 9.3.3

    The P-value (or probability value) is the probability of obtaining a test statistic at least as extreme as the one observed, assuming the null hypothesis is true.

    The P-value tells us how “surprising” our sample result would be if H0 were true. A small P-value indicates that the observed result would be unlikely if H0 were true, which provides evidence against H0.

    Decision Rule Using P-Value

    Procedure 9.3.5 Decision Rule Using P-Value
    • If P-value <α, reject H0.
    • If P-value ≥α, fail to reject H0.

    §9.3 Example 1

    MATH 11

    Using the P-Value Method

    For each scenario, use the P-value method to determine whether to reject or fail to reject the null hypothesis.

    1. (a) A left-tailed test with α=0.05 yields a P-value of 0.0418.Since P-value =0.0418<0.05=α, we reject H0.
    2. (b) A two-tailed test with α=0.05 yields a P-value of 0.0380.Since P-value =0.0380<0.05=α, we reject H0.
    3. (c) A right-tailed test with α=0.01 yields a P-value of 0.0100.Since P-value =0.0100≥0.01=α, we fail to reject H0.

    MATH 11

    Using Excel for P-Values

    Procedure 9.3.7 Using Excel for P-Values

    To find P-values for different test statistics:

    • For z-tests:
      • Left-tailed: =NORM.DIST(z, 0, 1, TRUE)
      • Right-tailed: =1-NORM.DIST(z, 0, 1, TRUE)
      • Two-tailed: =2*(1-NORM.DIST(ABS(z), 0, 1, TRUE))

    §9.3 The Critical Value Method

    MATH 11

    The Critical Value Method

    An alternative to the P-value method is the critical value method, which compares the test statistic to a critical value that defines the boundary of the rejection region.

    Definition 9.3.8

    The critical value is the value that separates the rejection region from the non-rejection region. The critical region (or rejection region) is the set of all values of the test statistic that would cause us to reject H0.

    §9.3 The Critical Value Method

    MATH 11

    Decision Rule Using Critical Values

    Procedure 9.3.9 Decision Rule Using Critical Values
    • If the test statistic falls in the critical region, reject H0.
    • If the test statistic does not fall in the critical region, fail to reject H0.

    §9.3 Example 2

    MATH 11

    Using the Critical Value Method

    For each scenario, use the critical value method to determine whether to reject or fail to reject the null hypothesis.

    (a) A left-tailed z-test with α=0.05 yields a test statistic of z=−1.71. The critical value is −z0.05=−1.6449.

    Since the test statistic z=−1.71<−1.6449=−z0.05, the test statistic falls in the critical region. We reject H0.

    §9.3 Example 2, continued

    MATH 11

    Using the Critical Value Method

    (b) A two-tailed t-test with α=0.05 and df=15 yields a test statistic of t=−1.94. The critical value is −t0.025=−2.131.

    Since |t|=|−1.94|=1.94<2.131=t0.025, the test statistic does not fall in the critical region. We fail to reject H0.

    §9.3 Example 2, continued

    MATH 11

    Using the Critical Value Method

    (c) A right-tailed z-test with α=0.01 yields a test statistic of z=2.51. The critical value is z0.01=2.3263.

    Since the test statistic z=2.51>2.3263=z0.01, the test statistic falls in the critical region. We reject H0.

    §9.3 Stating Conclusions

    MATH 11

    Stating Conclusions

    The final step in a hypothesis test is to state the conclusion in non-technical terms that can be understood by someone without a statistics background. The wording of the conclusion depends on two factors:

    1. Whether we reject or fail to reject H0
    2. Whether the original claim involves equality or not

    §9.3 Stating Conclusions

    MATH 11

    Formulating the Conclusion

    In each phrase below, replace the ellipsis with the specific claim being tested.

    Claim to test is H0“There is sufficient evidence to warrant rejection of the claim that…”“There is insufficient evidence to warrant rejection of the claim that…”
    Claim to test is H1“There is sufficient evidence to support the claim that…”“There is insufficient evidence to support the claim that…”

    §9.3 Example 3

    MATH 11

    Stating a Conclusion

    Suppose we conduct a hypothesis test with H0:μ≤30 and H1:μ>30 to test the claim that the mean commute time is more than 30 minutes. If we reject H0, how should we state our conclusion?

    The claim (that the mean commute time is more than 30 minutes) does not include equality, so the claim is H1. Since we rejected H0, we would say:

    “There is sufficient evidence to support the claim that the mean commute time is more than 30 minutes.”

    §9.3 Example 4

    MATH 11

    Stating a Conclusion

    Suppose we conduct a hypothesis test with H0:p=0.25 and H1:p≠0.25 to test the claim that 25% of shoppers use a coupon. If we fail to reject H0, how should we state our conclusion?

    The claim (that 25% of shoppers use a coupon) includes equality, so the claim is H0. Since we failed to reject H0, we would say:

    “There is insufficient evidence to warrant rejection of the claim that 25% of shoppers use a coupon.”

    §9.3 Comparing the Two Methods

    MATH 11

    Comparing the Two Methods

    Both the P-value method and the critical value method will always lead to the same conclusion. The P-value method is often preferred because:

    • It provides more information (the exact probability)
    • It is easier to use with technology
    • It allows readers to apply their own significance level

    The critical value method is useful for understanding the conceptual basis of hypothesis testing and is commonly used when working by hand with tables.
